# Megh Patel — Data Analyst Portfolio

A lightweight, responsive portfolio built with plain HTML, CSS, and JavaScript. It presents two selected data analysis projects with concise case studies and links to their source repositories.

## Run locally

Open index.html in a browser. No build step or package installation is needed.

## Featured projects

- [Consumer Complaints Analysis](https://github.com/meghp2356/consumer-complain) — PostgreSQL, SQL, Power BI
- [Data Analyst Job Market 2023](https://github.com/meghp2356/data-analyst-job-market-2023) — SQL

## Deploy

Import this repository into Vercel. The site is static and can be deployed with the default settings.
